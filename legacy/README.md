# 원본 보관

마이그레이션 전 단일 HTML 블로그입니다. **빌드에 포함되지 않습니다.**

- `index.html.original` — 89KB 단일 파일. 글 7편 × 한/영, 용어 40개, 표지 SVG 7개가 모두 이 안에 있었습니다
- `staticwebapp.config.json.original` — 마이그레이션 전 라우팅 설정

옮긴 내용이 원본과 다른지 확인할 때 대조용으로 씁니다. 새 사이트가 안정되면 지워도 됩니다.

## 마이그레이션 도구

옮기는 데 쓴 스크립트도 함께 두었습니다. 재현하거나 다시 검증할 때 씁니다.

| 파일 | 하는 일 |
|---|---|
| `data.mjs` | 원본 index.html 의 341~920행(GLOSSARY / SITE / ART / POSTS)을 그대로 떼어낸 모듈 |
| `migrate.mjs` | 위 데이터를 MDX 14편 + `src/data/*.ts` 로 변환 |
| `verify.mjs` | 원본 본문과 빌드된 페이지의 텍스트를 글자 단위로 대조 |

```bash
node legacy/verify.mjs deploy    # npm run build 뒤에 실행
```

마지막 실행 결과: **본문 14/14 일치, 제목·발췌·카테고리·날짜·읽는 시간 모두 일치.**

### 옮기면서 고친 것

- `<em>` 을 `_..._` 로 옮기면 "\_강조\_를" 처럼 한글 조사가 붙었을 때 CommonMark 가
  강조를 닫지 못합니다. `*...*` 로 바꿔야 합니다
- 날짜는 UTC 로 읽어야 합니다. 로컬 시간대(애리조나 UTC-7)로 읽으면 하루씩 밀립니다

## 다시 돌릴 때 주의

`migrate.mjs` 는 `src/content/notes/**` 를 **덮어씁니다.** 글을 손으로 고친 뒤에는
돌리지 마세요. 표지 도식(`art`)과 공유 카드 사진(`photo`) 배정은 스크립트 안의
`PHOTOS` / 슬러그 배열에 들어 있어 재실행해도 같은 결과가 나옵니다.
